Thermodynamic Computer Reference

This design is a digital stand-in for a probabilistic computer. It stores a model (couplings Jij and biases hi) and resamples one spin si ∈ {−1, +1} at a time, so that over many sweeps each spin state appears with its Boltzmann probability. Where the source papers make each decision with noisy transistors, this design uses an LFSR for the noise, a 1024-entry ROM for the sigmoid and a 16-bit comparator for the threshold. The map below follows one signal from a UART byte down to the transistors that hold and switch it.

L5Board top

One clock, one synchronous reset. Reset is held for the first 15 cycles by a 4-bit power-on counter and whenever S1 is pressed; both buttons pass through a two-flop synchronizer, and S2 also through an 18-bit debounce counter. The command FSM is the only master: nothing in the engine starts unless the FSM pulses arr_run.

L4Dense engine: pbit_array

A sweep visits all N nodes in the stored order. For each node the engine reads its index and bias, streams row i of J through a conditional adder (spins are ±1, so the multiply is a sign flip), runs the p-bit, and writes the new spin straight back. Because colour block 0 is visited before block 1, sequential updates inside a block equal the parallel block update of the source architecture.

Sparse lanes: sparse_array

For graphs of degree ≤ D, each node needs only D neighbour words. The host pre-arranges every colour block into rounds of P nodes (one per lane) and pads short rounds with valid = 0. Each lane has its own node RAM, neighbour RAM, accumulator, p-bit and LFSR lane; they share the round pointer, the slot counter and the spin register.

Noise options (NOISE_CTL = 1): with nz_tau each valid lane draws once in S_PB; a draw ≥ nz_q means "not decorrelated yet", so the lane keeps its spin and its p-bit draw is not consumed. With nz_share every lane reads lane 0's draw and only lane 0 advances, giving fully correlated noise inside a round.

Parallel tempering: temper_ctrl

K ≤ 4 replicas share the one dense array. A round sweeps each replica once at the β of its current rung, then tries swaps between neighbouring rungs: pairs (0,1) and (2,3) on even rounds, (1,2) on odd rounds. Acceptance is Barker's rule, σ((βa − βb)(Ex − Ey)), computed by a second p-bit with field = Δe and beta = |Δβ|. Default ladder (Q4.4): β0 = 3.0, β1 = 2.0, β2 = 1.25, β3 = 0.75. spins_out, the readout and the LEDs always show the replica sitting on rung 0.

Langevin p-modes: pmode_array

Continuous soft spins xi in a double well, driven by overdamped Langevin dynamics. One step: x′ = x − 2−k dV/dx + σξ with dV/dxi = −(1 − si²)(Σj Aij sj + hi) + λ xi(xi² − 1) and s = tanh x. Defaults: λ = 2.0, ε = 1/16, σ = 0.3535 (T = 1). On the board, S2 toggles running, one step every 220 clocks, and LED k is lit while xk ≥ 0.

Clamped wrappers: pgate and denoise_demo

pgate: invertible logic

The gate's J and h make its truth-table rows the lowest-energy states. On start the wrapper latches clamp_mask / clamp_val and rewrites the bias RAM in N cycles: a clamped node gets h = +127 (0x7F) or −128 (0x80), any other node gets its stored h0. Clamp the inputs and the gate runs forward; clamp the output and it runs backward. Sequence: IDLE → BIAS (N) → RUN → WAIT (n_sweeps) → done. With K > 1 the run goes through temper_ctrl.

denoise_demo: denoising chain

Starts from xT and runs T = 4 steps on one array. Each step: load spins ← xt, rewrite every bias to sat8(hi ± Γt/2) with the sign of xti (N cycles), run K = 16 sweeps at β = 1.0, take the spins as xt−1. step_done pulses after each step, done after t = 1. The same hardware is reprogrammed at every step.

L3The p-bit decision

Every sample in every engine passes through this block (dense, each sparse lane, and the tempering swap). The product β·field arrives with 8 fraction bits; doubling it and keeping 5 fraction bits is a right shift by WFRAC − 2 = 2 with round-half-up. The 10-bit logit is offset by 512 to address the ROM.

One dense update, every mechanism it touches

  • 2 SSRAM reads (order, bias) and N BSRAM reads (one row of J)
  • N add-or-subtract operations on a 14-bit carry chain, each steered by one spin through an N:1 mux
  • 8 conditional 23-bit adds (β·field), one rounding add, two saturation compares
  • 1 BSRAM read (σ), one 16-bit compare against the noise draw
  • One 32-bit LFSR leap through the XOR network (16 Galois steps in one clock)
  • One indexed spin write; at the end of a sweep, one pulse to the schedule and the counters

Noise lanes: lfsr and noise_bank

Lane k uses its own maximal-length polynomial (different m-sequences, not shifted copies) and seed = SEED ⊕ (0x9E3779B9 · (k+1)). Asserting en consumes the current draw. Default SEED = 0xACE1F00D.

Annealing and readout

schedule_ctrl

Holds β in an 8-bit register. Mode 0 keeps β0. Mode 1 adds Δ every SPS sweeps and saturates at β1. Mode 2 (the default) steps through a 16-entry table every SPS sweeps and holds at entry 15. The power-on default is mode 2, SPS = 8, so 16 × 8 = 128 sweeps (DEMO_SWEEPS) cover the whole table. With parallel tempering the ladder replaces this β.

readout_counter

On each swd pulse it counts one sample. The histogram is a 212 × 32 BSRAM indexed by the low 12 spins, updated by a 3-cycle read-modify-write. The up counters count how often each spin was +1: N parallel 32-bit incrementers in flip-flops, or with UP_RAM = 1 one BSRAM and an N + 1-cycle pipelined scan. A clear that arrives during a scan waits and runs right after it.

L0Transistors

An SRAM FPGA has no gates of its own: it is a large array of SRAM bits, pass transistors and fixed cells, and the bitstream decides which paths conduct. These are textbook structures; Gowin does not publish its cell layouts, so treat the drawings as the mechanism, not the exact circuit.

Findings from synthesis

Things the numbers show that the RTL alone does not.

The lane-0 LFSR mask is the most expensive small blockWith MASK = 0xB4BCD35C (18 taps) the 16-step leap synthesizes to 299 LUT4 + 186 MUX2 cells; lane 1's mask (4 taps, all in the top byte) needs 62 + 9. The dense build carries two lane-0 LFSRs (array and raw 'N' lane), about 26% of its LUT4s. A sparser maximal polynomial for lane 0 would save roughly 470 LUT4 per build, but model/fixed.LFSR_MASKS must change with it to keep the bit-exact mirror.
The readout counters are bigger than the samplerIn the dense N = 16 build, readout_counter uses 635 LUT4, 589 ALU and 681 DFF, mostly the 16 × 32-bit flip-flop counters. UP_RAM = 1 at N = 16 drops it to 195 LUT4, 114 ALU and 237 DFF for one extra BSRAM; its 17-cycle scan is far shorter than a 544-cycle sweep.
Every build meets 27 MHz with at least 2× marginPost-route Fmax ranges from 54.9 MHz (tempering) to 72.5 MHz (dense). The slowest path is the tempering swap setup: replica label lookup, 24-bit energy subtract and saturation into sf_reg. In the dense and sparse-16 builds the worst path is the schedule's 16-bit sweep-per-step compare driving the β register enable.
Sparse N = 256 nearly fills the chipWith P = 4 and D = 4 it places 7,009 LUT4 + 870 ALU, about 91% of the 8,640 logic sites. The 256:1 spin read mux in each lane and the 256-way spin write decoder dominate (sparse_array alone is 3,686 LUT4 + 2,246 MUX2 in Yosys). More lanes or a wider degree will not fit without restructuring the spin register.
The raw 'N' lane replays lane 0raw_noise_inst uses lane 0's polynomial and seed, and 'X' reseeds it together with the array. Its stream is the same sequence the dense array's lane 0 consumes, which is useful for checking the generator offline, not as an independent source.
