Machine learning on the chip

      
The p-bit array is a sampler for energy-based models. Training runs the chip in a loop (clamped and free phases, docs/09); inference pins what is known and samples the rest. Each card lists the engines that can run it; on the Python model a click connects the right chip. The ideal Python simulator (float weights, any size, model/pysim.py) runs the p-bit demos without the FPGA's limits, plus models too big for it.

      

      

    

    

  


  
  

    

      

        
UART wire

        
Every command the page sent to the engine and the bytes it answered (115200 8N1 on the board, 8 clocks per bit in the RTL). When programming, the host sends all W / H / O words first and reads their one-byte acks afterwards, so those acks are listed under the last command sent.

        

      

      

        
Model ≡ RTL check

        
Runs one session (program, reseed, 2000 sweeps, histogram, counters, 50 streamed samples) on the Python model and on the Verilog, and compares every reply byte.
